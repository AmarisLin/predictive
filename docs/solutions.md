# 驗收流程（含劇透）

1. 唯一作品名稱為聯想詞predictive。首頁只有標題與功能介面；每輪要回覆朋友的字句直接放在鍵盤內，不在聊天上方設提示框，不顯示章節、進度或結局解釋。
2. 回覆睡不著、輸入法怪怪的。第二段先輸入一字不送出，輸入第二個已提交字元後，候選「他在打字」約650ms後自行送出。原草稿僅兩個字，送出資訊記為自動；不得重複觸發。組字中不觸發。
3. 第一格跟遊戲內的打字、刪字、看詞庫等操作，與輸入內容無關。關閉一般聯想只停用普通候選，異常觀察仍在。
4. 詞庫初始41條，總使用759次（含地址）；新輸入再增加。畫面依使用次數顯示詞句、次數與時間，觀察詞在前面。第四段先打開詞庫，才解鎖提示帶入及送出。
5. 第五段清／不清都可走完。清除會變0條，保留聊天與草稿，鍵盤回覆字句變「清掉了。」；不清提示為「先不清，我再試試。」。後期觀察操作能重新出現在詞庫。
6. 地址段先進詞庫複製城南路118號2樓，關閉後按貼上地址並送出；手動輸入而未複製不能過關。清空路線地址會在此段再出現。之後朋友要求照片，照片段才可打開附件。本機用 assets/hallway-local.png，有遠處站立人影；傳出氣泡用 assets/hallway-sent.png，為空走廊。朋友只評論正常版本。
7. 照片後要先比對兩張照片才回覆，提示可直接進入比對。桌面並排，窄螢幕上下。所有照片來自原創生成，不使用相機。
8. 在照片後兩輪打字，第一格依序為他在打字、他發現了；輸入內容任意。刪字或看詞庫仍能顯示相應操作觀察。
9. 照片後先互道晚安，再傳睡了嗎？並顯示未讀，朋友離線且不回覆。接著鍵盤顯示看它的頭，可點字句逐字帶入、直接打字或使用畫面鍵盤。組字提交後三格全部不能看，無需送出。舊的看它的臉不再觸發。
10. 三格警告停兩秒，黑屏三秒後慢慢亮起，然後到07:12鎖屏。朋友兩條訊息依序詢問昨晚03:47的他睡著了，再問你還好嗎。沒有解釋卡，兩條訊息後2000ms跳白底通知，選前往設定才進鍵盤設定；稍後則可再按查看設定。
11. 續讀 warning／black 會完成到早晨，續讀 morning 直接顯示兩條訊息。不混用v2/v3/v4存檔。暫停、重玩、切頁不會留下舊計時亂入。
12. 送出資訊、照片比對、保留與下載只記錄真正操作過的狀態。清詞庫不刪聊天、比對及保留紀錄。全部為本機虛構遊戲資料。

13. 早晨後點帳號與同步，預設帳號登入。確認框顯示2,347筆、1台裝置、03:47。取消回設定，可重新進入；同步1600ms後展示最近7條，前三條暗紅色：他睡著了03:47、救我03:46、它在床上03:44。其餘為別開燈、我也睡不著、床底下好冷、他睡了嗎。總數是虛構學習記錄，不宣稱能瀏覽全部2,347條。
14. 雲端設定、登入、取消、同步中及完成後續讀均保留正確狀態；同步完成才寫入本地遊戲詞庫。全流程零真實登入、零雲端網路請求。

15. 同步後詞庫停4000ms再詢問是否前往聊天室。稍後可繼續閱讀，再按前往聊天室；前往切成阿寧視角，對話對象蘇蘇，最後上線7天前。
16. 歷史三則與玩家送出的蘇蘇、你在哪都未讀。兩輪候選分別為睡著了／在床上／不會回來了，以及床底下／他床上／這裡。提示只在鍵盤，不在上方加解說。
17. 輸入我不看它的頭，組字提交後三格不要看；2200ms後黑屏1200ms、空電池2500ms，再白底手機電量不足／螢幕錄影已關閉通知。按好或5000ms後回首頁聯想詞，沒有繼續，可直接開始重玩；本輪紀錄仍可查看。
18. 快模式訊息及恢復輸入間隔1100ms，正常1600ms，早晨兩條1400ms。暫停、重整可續讀通知與朋友視角；v5存檔驗證後升v6，完成狀態不再回尾聲。

最新操作規則：新遊戲先顯示三頁截圖教學，可從首頁或下方遊玩教學重看。只可點預設訊息逐字帶入，再按↑送出；不提供手動輸入、候選詞及字鍵輸入。地址仍需進詞庫複製再按貼上地址。教學依序框出預設訊息、查看詞庫、查看照片，截圖放assets/tutorial-*.jpg。對話改為「先檢查一下。」。此規則取代本文舊版自由輸入描述。
