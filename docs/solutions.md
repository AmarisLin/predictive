# 六結局驗收與攻略（含劇透）
先走主線：預設訊息、兩字自動送出、查看詞庫、清／不清、複製貼上地址、傳照片並比對、晚安、睡了嗎未讀、看它的頭、不能看、黑屏漸亮與早晨通知。
- 4/6：早晨進設定，選關閉雲端同步。
- 其餘：登入並同步一次，到朋友視角。
- 2/6：傳蘇蘇後，選重新同步詞庫。
- 3/6：傳蘇蘇後，選傳送床底下。
- 1/6：傳蘇蘇、你在哪，照預設訊息輸入我不看它的頭；不要看→沒電→錄影關閉→結局1/6。
- 5/6：傳蘇蘇、你在哪，停止輸入，選停止同步改語音。
- 6/6：停止輸入後查看照片與詞庫線索，再依線索確認來源，選先別抬頭、照片是哪裡；兩人離開，揭露求救和警告來自蘇蘇，觀察句來自床上的存在。
真結局門檻尚未滿足時要有文字說明。再次回覆床底下會走3/6。結束後看編號、類型、解鎖進度，回首頁及重玩；進度保存並去重。逐則訊息1.1／1.6秒，暫停重整不重播已到達訊息。
