# 完整流程與驗收（含劇透）

## 流程
首頁聲音提醒 → 三頁截圖教學／一頁手機操作教學 → 阿寧叫蘇蘇 → 輸入法異常 → 兩字自動發送 → 個人詞庫 → 清或不清 → 複製／貼上店家地址 → 本機照片有人／傳出無人 → 比對 → 固定他在打字／他發現了 → 晚安 → 睡了嗎未讀 → 阿寧未讀 → 看它的頭 → 四格不能看 → 黑屏3秒 → 漸亮早晨 → 兩條通知 → 設定／登入／模擬同步 → 雲端最近7條 → 前往聊天室 → 阿寧視角 → 蘇蘇／你在哪 → 兩結局分歧。

結局1：預設我不看它的頭完整帶入 → 四格不要看 → 旋轉90度／橫向約一秒／回直向 → 黑屏 → 空電池 → 錄影關閉通知 → 結局1及指定兩行小字。
結局2：小格撥號 → 兩聲嘟 → 接通2秒 → 通話結束 → 回聊天室語音通話0:02 → 蘇蘇傳不要看 → 結局2及指定兩行小字。
