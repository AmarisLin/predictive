# 聯想詞predictive

十三段連續手機聊天恐怖互動。玩家抱怨輸入法會自行送出，第一個聯想詞卻開始描述玩家的操作。朋友不相信，建議清詞庫、傳照片確認；本機照片和傳出去的照片，卻不是同一個結果。

## 遊玩
開啟 index.html，按開始。每輪都有鍵盤回覆字句，可自行打字或按鍵盤回覆字句逐字帶入，再按 ↑。候選點選只接字；指定段落會在輸入兩個已提交字元後自動傳出，保留原文供送出資訊比對。手機中文輸入法、實體鍵盤及畫面中文字鍵盤皆可用。
右上角 ··· → 個人詞庫，能查看詞句、使用次數與最近時間，並真正清除本輪詞庫。歷史詞句與操作觀察均為虛構，不會讀取真正的輸入法。
朋友要求照片後，按 ＋ 查看本機照片並傳送。氣泡中的已傳送照片可再點開；比對照片會並排顯示本機原圖與已傳送版本。桌面放大對照，窄螢幕上下排列。
點送出資訊可比對原文與自動傳出的文字。紀錄可保留原始草稿並下載 UTF-8 predictive-record.txt。音效預設關閉，有低動態、訊息速度、暫停、續讀及重玩。
朋友索取地址時，進詞庫按「複製地址」，關閉後在鍵盤按「貼上地址」並送出。清除路線也能完成。最後有明確的指定輸入提示，互道晚安後傳「睡了嗎？」並停在未讀，接著輸入「看它的頭」。三秒黑屏與漸亮後，早晨兩條通知依序到達，先詢問是否前往設定，再進入預設帳號與雲端詞庫同步。同步後詢問是否前往聊天室，切到阿寧尋找蘇蘇的第七天；輸入蘇蘇、你在哪、我不看它的頭，候選警告後手機沒電，顯示錄影關閉通知並回首頁「聯想詞」。登入與同步為本地劇情模擬，不需要真實帳密。完整驗收含劇透，見 docs/solutions.md。

## 檔案與生成式 AI
AGENTS.md 是維護及擴充規則；story.js 管理對話、鍵盤回覆字句、詞庫與通知；engine.js 為純狀態；game.js 為輸入與畫面。art.js 指向兩張原創生成照片，素材與提示詞在 docs/assets.md。
生成式 AI 協助企劃、程式、照片與文件；遊戲使用固定劇本及操作狀態，未即時連接模型，也不讀取玩家真實動作。

```sh
node scripts/check.mjs
node --check story.js
node --check engine.js
node --check game.js
node --check art.js
python3 build.py
```
零套件、無 API 金鑰。可直接開 HTML，建議用靜態網站以取得穩定儲存。
本版使用 predictive-story-v8；可驗證遷移v7／v6／v5存檔；v2/v3/v4舊存檔保留，不混接新主線。瀏覽器封鎖儲存時仍可玩，但關閉後不能續讀。

## GitHub 與作業繳交
1. 建立 Public Repository，例如 predictive-story。
2. 上傳解壓後來源檔、assets、scripts、docs；index.html 與 AGENTS.md 在根目錄，不直接上傳 ZIP。
3. Settings → Pages → Deploy from a branch → main、/(root) → Save。
4. 以未登入視窗驗證真正的公開網址，再填入 docs/submission.txt 的 Repository、網頁與 AGENTS.md 連結。
目前 ChatGPT Site 沿用網址與擁有者存取設定，需要登入，不取代老師可直接開啟的公開 Pages。

## 三個結局
只保留結局1/3斷線（原本）、2/3天亮（存活）、3/3離線（假性安全）。最後沒有查看線索、真結局或真相解說，透過手機設定和語音通話選擇分歧。四頁操作教學；首頁保存結局收藏。執行node scripts/branches-check.mjs可驗證三路線與舊進度映射。GitHub Pages需上傳新版才更新。

最新介面：最後預設訊息「我不看它的頭」佔大格，語音通話佔旁邊25%小格。結尾與收藏只顯示結局1、結局2、結局3，不顯示結局名稱或類型。

最新結尾：開場阿寧先叫蘇蘇再問還沒睡。結局1依序淡入手機被找到與充電後錄影；結局2通話只出現蘇蘇「不要看」「快跑」，只有阿寧存活，結尾顯示通話時間168小時37分13秒及蘇蘇失蹤七天；結局3關閉同步後短暫正常，聯想詞顯示「後面」，必須點預設「她睡著了」逐字輸入才出結局3／你也睡不著嗎。第二行字更小更淡，支援低動態。存檔v9，branch revision3；保留舊收藏與相容已完成結局，新離線分支可中途續讀。
